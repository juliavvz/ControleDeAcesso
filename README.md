Sistema de Controle de Acesso

Projeto desenvolvido em C# como atividade acadêmica sobre a estrutura de dados Fila (Queue).

Objetivo

Desenvolver uma aplicação Console para controlar o acesso de usuários a diferentes ambientes, verificando permissões e registrando todas as tentativas de acesso.

Funcionalidades

- Cadastro, consulta e exclusão de usuários.
- Cadastro, consulta e exclusão de ambientes.
- Concessão e revogação de permissões.
- Registro de acessos autorizados e negados.
- Consulta e filtragem dos logs.
- Armazenamento dos últimos 100 registros por ambiente.
- Salvamento e carregamento dos dados em arquivo JSON.

Tecnologias utilizadas

- C#
- .NET
- Console Application
- Estrutura de dados Queue (Fila)
- JSON para persistência dos dados.

Como executar

1. Clone o repositório.
2. Abra o projeto em uma IDE compatível com C# e .NET.
3. Execute a aplicação.
4. Utilize o menu apresentado no console para acessar as funcionalidades.
